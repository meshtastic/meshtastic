## [Pocket-Ranger/Scout](./pocket-ranger/)

Injection molded weather resistant node perfect for a daily carry mesh communication device. Hardware and software is customized for long battery operated sessions by utilizing RX Duty Cycle and getting best-in-industry battery life.

## [Outdoor PoE v1 Node](./outdoor-poe-v1/)

Outdoor repeater style device that can be powered using 5v DC jack, USB-C or PoE. There is no support for data over the PoE and is only used to power the device. This device is perfect to act as a repeater. Provided in the box is a +3dBi fiberglass antenna, perfect for the outdoors.

| Name                                       | MCU      | Radio  | WiFi | BT  |  GPS   |
| :------------------------------------------| :------- | :----- | :--: | :-: | :----: |
| [Outdoor PoE v1 Node](./outdoor-poe-v1/)   | nRF52840 | SX1262 | NO   | 5.0 | NO     |
