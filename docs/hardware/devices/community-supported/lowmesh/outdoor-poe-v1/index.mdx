[Outdoor PoE v1 Nodes](https://lowmesh.com/devices) can be powered using 5v DC jack, USB-C or PoE. There is no support for data over the PoE and is only used to power the device. This device is perfect to act as a repeater. Comes with a +3dBi fiberglass antenna, perfect for the outdoors.

## Specifications

- **MCU**
  - nRF52840 (Bluetooth 5 LE)
- **LoRa Transceiver**
  - Semtech SX1262
- **Frequency options**
  - 915 MHz
- **Antenna**
  - Fiberglass antenna, +3dBi Gain (N-Type)
- **Connectors**
  - USB-C
  - N-Type
  - RJ45 for Power over Ethernet (PoE)
  - 5v DC jack
- **Durability**
  - Outdoor-rated enclosure

## Features

- Mast, pole, and wall mounting options
- Diagnostic LED
- [Custom firmware](https://lowmesh.com/flasher), providing up to 4 weeks of runtime
