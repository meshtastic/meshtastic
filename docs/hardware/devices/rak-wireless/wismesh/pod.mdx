The WisMesh Pod (RAK10708) is a pocket-sized Meshtastic node with GNSS, a buzzer, and a 1000 mAh battery. It ships pre-flashed with Meshtastic firmware.

## Specifications

- **MCU**
  - nRF52840
    - Bluetooth 5.0 LE
    - Very low power consumption
- **LoRa Transceiver**
  - SX1262
- **Frequency Options**
  - 860–930 MHz, one hardware version for all regions
- **GNSS Module**
  - AT6558
- **Battery Capacity**
  - Rechargeable lithium battery, 1000 mAh
- **Connectors**
  - USB-C for charging, flashing, and serial
- **Size and Weight**
  - 110.9 × 42.3 × 16.6 mm (4.37 × 1.67 × 0.65 in)
  - 108.7 g (3.83 oz)

## Features

- Integrated LoRa, Bluetooth, and GNSS antennas.
- Integrated acceleration sensor based on ST LIS2DH.
- Buzzer and status LEDs for notifications and charging.
- One button for power, reset, and DFU (Device Firmware Update) mode. Meshtastic firmware assigns it no user functions.
