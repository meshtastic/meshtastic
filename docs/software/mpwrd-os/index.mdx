mPWRD-OS is a Linux distribution for single-board computers that pairs [Armbian](https://armbian.com/) with Meshtastic. Its images are based on Debian 13 `trixie` and ship with [meshtasticd](/docs/meshtasticd) and the [Meshtastic Python CLI](/docs/software/python/cli) already installed, so the node software is ready to configure as soon as the board boots. Images and source are published at [mPWRD-OS/mPWRD-OS](https://github.com/mPWRD-OS/mPWRD-OS).

## What's included

| Component | Purpose |
| --- | --- |
| Debian 13 `trixie` | Base system, built with the Armbian userpatches framework |
| [meshtasticd](/docs/meshtasticd) | Runs the Meshtastic node firmware on the board |
| [Meshtastic Python CLI](/docs/software/python/cli) | Configures the node from a shell |
| [contact](https://github.com/pdxlocations/contact) | Terminal client for reading and sending messages |
| [mpwrd-menu](https://github.com/mPWRD-OS/mpwrd-menu) | Menu-driven setup for system and Meshtastic settings |
| Wi-Fi provisioning | Sends Wi-Fi credentials to a board that has no network connection yet |

## Install and set up

1. Download the image for your board from the [mPWRD-OS releases](https://github.com/mPWRD-OS/mPWRD-OS/releases) page.
2. Prepare the board if it needs it. Boards with onboard NAND flash or eMMC are handled in [Rockchip flashing](/docs/software/mpwrd-os/rockchip-flashing).
3. Write the image to a microSD card with [balenaEtcher](https://etcher.balena.io/) or a similar tool, then power on the board. Writing the image erases everything on the card.
4. Connect to the board. Boards with an Ethernet port are reachable over SSH once they join your network, and boards without one take the Bluetooth or hotspot route described in [Provisioning](/docs/software/mpwrd-os/provisioning).
5. Log in as `root` with the password `1234`. The first login prompts for a new password.
6. Run `mpwrd-menu` to set your region, configure the radio, and change system settings.

   ```shell
   mpwrd-menu
   ```

## Building your own image

The repository is an Armbian userpatches overlay, so images are compiled by [armbian/build](https://github.com/armbian/build) with mPWRD-OS checked out as `userpatches`. Each board has its own configuration file in the repository. The [repository README](https://github.com/mPWRD-OS/mPWRD-OS#using-this-repo) carries the commands.
