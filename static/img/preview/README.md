## What is in this directory

Social preview cards: the images shown when a page on meshtastic.org is linked from chat or social media. Each carries the Meshtastic mark and wordmark.

These are build outputs, generated rather than drawn by hand, and are committed so the site can serve them. `hardware-1200x630.png` is built by `pnpm preview:hardware`; see `scripts/README-hardware-preview.md`. Regenerating a card does not change its status under the notice above.
